# Lost Ark Stagger Tool

**Retired for now.** The calculator is offline because the stagger calculation logic was never validated well enough to rely on the values it displayed.

[Current status page](https://thejunglewalrus.github.io/lost-ark-stagger/)

The original calculator remains in this repository's Git history, and the data files are preserved for a future revisit. Do not use the previous values as a raid reference.

## How it's built

This repository contains the static site only. The Python build pipeline that
generates the data files lives in a separate local project — the JSON under
`data/` is the baked output of that build.
